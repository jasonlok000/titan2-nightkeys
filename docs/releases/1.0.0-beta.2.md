# NightKeys 1.0.0-beta.2

## Three-step setup

1. Install Shizuku if it is not already installed (automatically detected).
2. Start Shizuku, return to NightKeys, and connect/authorize.
3. Enable NightKeys. Android may ask for notification permission.

No 90-second check, saved hardware-confirmation checklist, or brightness capture.
The working lighting algorithm remains unchanged: default 10/15 lux, immediate dark
activation, 250 ms bright debounce, explicit OFF on screen-off and exact original
timeout restoration. Your stock brightness remains untouched. The installer still
refuses unsupported hardware, unavailable transport, and unresolved recovery.

The Titan Tools page now has a proportion-matched Titan 2 Elite illustration and
physical keyboard layout, retaining the interactive dark/bright/sleep demonstration.

## Install/update

For community beta.1: Stop & restore, then install the APK as a normal update; the
permanent certificate is unchanged. For 0.9.x trials: restore first and uninstall
once because those trial signing keys differ. There is no need to repeat setup
verification because that prerequisite no longer exists.

## Limitations

Titan 2 Elite, Android 16, owner profile; baseline owner-tested on V02.00.04.
Unexpected app/Shizuku termination can leave the persistent timeout changed. No
independent watchdog. Always Stop & restore before removal, clearing data or stopping
Shizuku. APK readback and emulator tests cannot measure the physical LEDs.
