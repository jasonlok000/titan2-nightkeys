# NightKeys 1.0.0-beta.3

## ⚠️ Reinstall once: new signing key

The signing key used for beta.1 and beta.2 was lost, so this version is signed with a
new key. Android will not install it over the old app. Do this once:

1. Open your current NightKeys and tap **Stop & restore**.
2. Uninstall NightKeys.
3. Install **NightKeys-1.0.0-beta.3.apk** below and do the one-time setup again.
   Shizuku stays paired, so it's quick.

Updates after beta.3 will install normally. The new certificate's SHA-256 is
`bb769da3c4aa70bf9e50604df662153998ce64baf410ee0cd3e7579afafa9420`
(also in `signing-certificate.sha256`).

## A simpler main screen

- One top card shows the status, the live room light and the **How dark is dark enough?**
  slider together.
- **One-time setup** sits above **Enable NightKeys**: Get Shizuku → Start Shizuku →
  Allow NightKeys. Finished steps get a tick, and one big button always shows the next
  step. The card hides once setup is done and comes back if Shizuku stops (e.g. after
  a restart).
- Plain-language hints replace the technical Shizuku/agui_common status lines.
- The keyboard-brightness shortcut is gone. NightKeys still uses whatever brightness
  you set in the phone's own settings.
- Help, battery settings, support report and licences are folded into
  **Advanced settings**.

The lighting itself is unchanged: on below 10 lux, off at 15 lux, off with the screen,
and your original keyboard timeout is restored on Stop & restore.

## Limitations

Titan 2 Elite, Android 16, main user; baseline owner-tested on V02.00.04. If the app
or Shizuku is killed unexpectedly, the keyboard timeout can stay changed. There is no
independent watchdog. Always tap Stop & restore before uninstalling, clearing data or
stopping Shizuku. Emulator tests cannot measure the physical keyboard LEDs.
