# NightKeys 1.0.0-beta.1

The first open-source community beta for the **Unihertz Titan 2 Elite**.

## Download and setup

Download **NightKeys-1.0.0-beta.1.apk** from the assets below. Do not download the source ZIP to install the app. No GitHub account is required.

[Every-step setup guide in the repository](https://github.com/jasonlok000/titan2-nightkeys/blob/main/docs/SETUP.md) · [Visual setup website](https://jasonlok000.github.io/titan2-nightkeys/setup.html) · [Report a problem](https://github.com/jasonlok000/titan2-nightkeys/issues/new?template=bug_report.yml)

The Pages site may require its one-time owner activation; the repository guide always remains available.

## What changed

- Focused onboarding and an Enable NightKeys / Stop & restore action.
- Manual hold, force-off and diagnostic monitor controls removed from the shipped app. Read-only, opt-in support report retained.
- The working 0.9.7 timing is preserved: dark activation from a fresh sample, 250 ms bright debounce, explicit screen-off shutdown. Stock keyboard brightness is untouched.
- Normal Gradle source build with permanent release signing, source archive, checksums and public signing certificate.
- Developer docs, contribution forms, privacy/safety notes and Titan Tools website with a visual light demo.

## Compatibility and test scope

Requires Titan 2 **Elite**, Android 16, main owner profile and running authorized Shizuku. Working baseline confirmed by the maintainer on **V02.00.04**; the newly signed community build must still pass the physical check on your phone. Regular Titan 2 and other models are not supported by this release.

Automated gates before signing: JVM policy/recovery tests, Android debug/release build and lint, real non-root Shizuku (shell UID 2000) tests on an Android 16 emulator, and desktop/mobile website interaction checks. An emulator does not contain the Unihertz keyboard service or LEDs.

## Important limits

The ON timeout is still a persistent, very large value. This beta has **no independent watchdog**. If NightKeys or Shizuku is killed, the setting may remain changed, including light while the display is off on the tested firmware. **Always use Stop & restore before uninstalling, clearing data or stopping Shizuku.** Keep app data until restoration succeeds.

After a phone reboot, start Shizuku again and open NightKeys. Avoid the stock keyboard-light Quick Settings tile and other backlight controllers while NightKeys is active. Read [Safety and recovery](https://github.com/jasonlok000/titan2-nightkeys/blob/main/docs/SAFETY.md).

The 90-second setup check is temporary. Save the successful check, wait for restoration, then tap **Enable NightKeys** for everyday use.

## Updating from 0.9.x trials

Stop & restore the old trial and confirm no pending hardware changes, then uninstall it once. The new permanent community signing certificate differs from the disposable trial keys. Future community releases must retain this new key so ordinary updates work.
