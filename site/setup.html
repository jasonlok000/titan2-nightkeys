First, get NightKeys

For Titan 2 Elite, Android 16, main owner profile. The working baseline is firmware V02.00.04. A regular Titan 2 is not the same phone.

Download NightKeys APK

Open the completed download, then tap Install → Open. If Android asks, temporarily allow installation from that browser. You can turn that permission off afterwards. No GitHub account is needed.

Where do I find the file? What about Android warnings?

Look in your browser’s Downloads menu or the Files app → Downloads. The filename ends in .apk, not .zip or .idsig. On the release page, it is under Assets. Do not disable Play Protect or ignore a harmful-app warning.

Already have an earlier NightKeys?

Tap Stop & restore in the old app first. Community beta.1 updates normally to this version with the same signing key; no uninstall needed. Older 0.9.x trials need one uninstall because they used a different key. Do not remove an old app with a pending recovery record.

Open NightKeys. Its three setup steps match the guide below.

01

Install Shizuku, if needed

Shizuku lets NightKeys change the keyboard timeout without rooting your phone. NightKeys detects it automatically: if step 1 says “Already installed,” go straight to step 2.

  1. Tap Get Shizuku in NightKeys. It opens the official download page.
  2. Choose its Play Store or official GitHub download. Install Shizuku and open it. Allow its notifications so the pairing prompt can appear.
  3. Return to NightKeys. Step 1 now shows that Shizuku is installed.

Official Shizuku downloads ↗

“Not running” in Shizuku is normal at this point. Installing it is not the same as starting it.

02

Connect & authorize

If Shizuku already says Running, skip the first-time setup below. In NightKeys, tap Connect & authorize, then approve NightKeys in the Shizuku prompt.

First time using Shizuku? Follow these taps.
  1. Connect your phone to a trusted Wi-Fi network. No computer is needed for this method.
  2. Open the phone’s Settings → About phone. Tap Build number seven times. Enter your own lock-screen PIN if Android asks; never share it.
  3. Return to Settings and search for Developer options (usually under System). Follow Shizuku’s instructions to enable USB debugging and Wireless debugging. Do not enable OEM unlocking.
  4. Open Shizuku → Pairing. Allow notifications if asked.
  5. Go to Wireless debugging. Tap the row to open its details, not just its switch. Tap Pair device with pairing code.
  6. Keep the six-digit code window open. Pull down the notification shade and expand Shizuku’s pairing notification. Tap Enter pairing code, enter those six digits and send them.
  7. Go back to Shizuku. Separately tap Start under wireless debugging. Wait for it to say Running.
  8. Return to NightKeys. Tap Connect & authorize. Choose Allow all the time in the Shizuku prompt.
No pairing notification, or Shizuku will not start?

Allow Shizuku notifications in Settings → Apps → Shizuku → Notifications. Check Wi-Fi and Wireless debugging, generate a new pairing code and keep its window open. Pairing alone is not enough: return to Shizuku and tap Start. Official setup help ↗

NightKeys should report “Shizuku authorized” and “agui_common ready.” This is a read-only compatibility check, not a timed lighting test.

03

Enable NightKeys

  1. Tap Enable NightKeys. You do not need to run a test or save a confirmation.
  2. If Android asks for notification permission, tap Allow. This provides a quiet running notification with a Stop & restore control.
  3. That’s it. Leave NightKeys and use your phone. In darkness, the keyboard stays lit while your screen is on. In a bright room or with the screen off, the keyboard switches off.

It uses your existing keyboard brightness and a default threshold of 10 lux. You can change those later under Optional preferences.

No 90-second expiry. Automatic lighting stays enabled until you stop it, or the service cannot continue.

A few useful things to know

Choose the minimum brightness

In NightKeys, open Optional preferences → Open keyboard brightness settings. Use the stock slider to choose the lowest level you can comfortably see. NightKeys does not alter it. The maintainer’s Elite reports value 7 at minimum, but you never need to type a number or confirm a calibration.

Make it work in a darker or brighter room

Under Optional preferences, lower the threshold to require a darker room, or raise it to light the keys sooner. The default turns on below 10 lux and off at 15 lux; the gap avoids flicker.

After restarting your phone

Start Shizuku again, then open NightKeys. You normally do not need to pair again. Resume can be enabled in NightKeys, but Android may block automatic restart. Tap Enable NightKeys if it is paused.

Keep it running in the background

Open NightKeys battery & app settings → Battery or App battery usage → Unrestricted, if available. Do the same for Shizuku if it keeps stopping. Labels vary by firmware. NightKeys keeps a quiet running notification.

Pause or uninstall safely

Use Stop & restore before uninstalling, clearing data or stopping Shizuku. Confirm the support report says no pending hardware changes. If restoration fails, keep the app data and start Shizuku to retry; a normal finite duration in stock Keyboard backlight settings is a manual recovery option.

This is a community beta. If the app or Shizuku is killed unexpectedly, the persistent timeout can remain changed and the keyboard may stay lit while asleep. There is no independent watchdog. If the light behaves incorrectly, use Stop & restore and report it.

Avoid the stock keyboard-light Quick Settings tile while NightKeys is enabled; both edit the same timeout. Pause NightKeys before using that tile.
