Start here: download NightKeys

NightKeys is free. It’s made for the Unihertz Titan 2 Elite only (not the regular Titan 2).

Download NightKeys

The file is called NightKeys-1.0.0-beta.3.apk. “.apk” just means an Android app file.

  1. Tap Download NightKeys above, on your Titan 2 Elite.
  2. When the download finishes, tap Open in the browser’s message. (Missed it? Open the Files app → Downloads.)
  3. Tap Install. If your phone says it can’t install apps from this browser, tap Settings, turn on Allow from this source, then go back and tap Install.
  4. Tap Open.

You should now see: NightKeys, with a One-time setup card and an Enable NightKeys button underneath.

Already have an older NightKeys installed?

This version is signed with a new key, so your phone won’t install it over the old one. Do this once: open your old NightKeys and tap Stop & restore, uninstall it, then install this download. You’ll do the setup steps again, but Shizuku stays paired. Future updates will install normally.

Checking your phone matches

Tested on the Titan 2 Elite with Android 16 and phone software version V02.00.04 (find it in Settings → About phone). It must be used by the phone’s main user, not a work profile or second user. Other software versions might work but haven’t been checked yet. If NightKeys says “This phone is not supported yet,” it won’t change anything on your phone.

01

Get Shizuku, the helper app

What is Shizuku? A free, popular helper app. Android normally won’t let an app control the keyboard light. Shizuku gives NightKeys that permission safely, without “rooting” (hacking) your phone.

Already have Shizuku? NightKeys notices automatically and ticks this step (“Installed”). Skip to step 2.

  1. In NightKeys, tap the big Get Shizuku button. It opens Shizuku’s official download page.
  2. Install Shizuku from Google Play (easiest) or the official GitHub link on that page.
  3. Open Shizuku once. If it asks to send notifications, tap Allow. You’ll need these in step 2.
  4. Go back to NightKeys.

You should now see: a tick next to “Get Shizuku” in NightKeys, and the big button now says Open Shizuku. Shizuku itself will say “Not running”. That’s normal. You’ll start it in step 2.

02

Connect Shizuku to NightKeys

This is the longest step, but you only do most of it once. Shizuku already says Running? Jump to part D.

A Turn on Developer options (one time only)

Developer options is a hidden settings page. Turning it on is safe and doesn’t change your phone by itself.

  1. Connect to your home Wi-Fi.
  2. Open Settings → About phone.
  3. Tap Build number 7 times in a row. If asked, enter your own screen-lock PIN (never share it with anyone).

You should now see: a small message: “You are now a developer!”

B Turn on Wireless debugging (one time only)

  1. Go back to Settings. Search for Developer options and open it (it’s usually under System).
  2. Turn on USB debugging. Shizuku’s official guide asks for this too. Tap OK if asked.
  3. Scroll to Wireless debugging and turn it on. Tap Allow if asked about this network.

You should now see: Wireless debugging switched on. Leave everything else alone. You never need “OEM unlocking.”

C Pair Shizuku (one time only)

“Pairing” is a one-time handshake that lets Shizuku use Wireless debugging. It’s like pairing a Bluetooth speaker.

  1. Open Shizuku. Under Start via Wireless debugging, tap Pairing.
  2. Go to Settings → Developer options. Tap the words Wireless debugging (not just its switch) to open that page.
  3. Tap Pair device with pairing code. A box with a 6-digit code appears. Leave it open.
  4. Swipe down from the top of the screen. Find Shizuku’s notification and tap Enter pairing code.
  5. Type the 6 digits and send.

You should now see: a Shizuku notification saying pairing succeeded.

D Start Shizuku and connect (after every restart, too)

Pairing and starting are different. Pairing happens once. Starting is like switching Shizuku on, and it’s needed again after each phone restart.

  1. Open Shizuku and tap Start (under Start via Wireless debugging).
  2. Wait a few seconds until Shizuku says Running.
  3. Open NightKeys. “Start Shizuku” now has a tick. Tap the big Allow NightKeys button. (If the button still says Open Shizuku, Shizuku isn’t running yet. Go back and tap Start.)
  4. A Shizuku box asks whether to allow NightKeys. Tap Allow all the time.

You should now see: NightKeys says “Ready for the dark” and “✓ Setup done”. The setup card disappears.

03

Turn on NightKeys

  1. In NightKeys, tap Enable NightKeys.
  2. If Android asks to allow notifications, tap Allow. NightKeys shows a small, quiet notification while it’s working, with a stop button.
  3. That’s it. Close the app and use your phone normally.

You should now see: “Automatic lighting is on. It continues when you leave the app.” In a dark room, your keys stay lit while the screen is on. In a bright room, or when the screen is off, the keyboard light turns off.

Button greyed out? See Enable button doesn’t work.

Stuck? Quick fixes

I can’t find the downloaded file

Open the Files app and tap Downloads, or open your browser’s menu → Downloads. Look for a file ending in .apk (not .zip or .idsig). Still nothing? Try the download button again, or use the release page and tap the .apk file under Assets.

My phone won’t let me install it

Android blocks app files from browsers until you say it’s OK. When it asks, tap Settings → turn on Allow from this source → go back → Install. You can turn that permission off afterwards. If Play Protect warns that an app is harmful, stop and ask for help. Don’t turn Play Protect off.

No Shizuku pairing notification

Shizuku needs permission to show notifications: Settings → Apps → Shizuku → Notifications → On. Then open Shizuku, tap Pairing again, and get a fresh 6-digit code. Keep the code box open while you type it into the notification.

I paired, but Shizuku still says “Not running”

Pairing doesn’t switch Shizuku on. Open Shizuku and tap Start. If it fails, check Wi-Fi is on, turn Wireless debugging off and on again, then tap Start again. Shizuku’s official help ↗

Enable button doesn’t work (greyed out)

It stays grey until the one-time setup above it is finished. The big setup button always shows what to do next: Open Shizuku (then tap Start), Allow NightKeys, or Try again. If NightKeys says “Restore your keyboard settings,” tap Stop & restore first. If it says “This phone is not supported yet,” this version can’t run on your phone.

After restarting your phone

Shizuku switches off whenever the phone restarts, so NightKeys shows its setup steps again. Turn on Wi-Fi, tap Open Shizuku → Start, then come back to NightKeys and tap Enable NightKeys if it’s paused. You normally don’t need to pair again. If Start fails, turn Wireless debugging off and on in Developer options.

Make it yours

Make the keys brighter or dimmer

Use the phone’s own keyboard backlight setting (open Settings and search for “keyboard”). NightKeys keeps whatever brightness you pick there.

Turn on in a darker or brighter room

In NightKeys, the top card has a “How dark is dark enough?” slider, right under a live reading of your room’s light. Lower number = the room has to be darker before the keys light up. Higher number = lights up sooner. (The numbers are light levels in “lux.” The default is fine for most people.)

It keeps stopping in the background

In NightKeys, tap Advanced settings → Battery settings → Battery (or App battery usage) → Unrestricted. Do the same for Shizuku if Shizuku keeps stopping. Names can differ slightly on your phone.

Pausing or uninstalling

Always tap Stop & restore in NightKeys first, before you uninstall it, clear its data, or stop Shizuku. That puts your keyboard light setting back the way it was.

Good to know: this is a community beta. NightKeys changes one keyboard-light setting while it runs. If NightKeys or Shizuku gets force-closed, that setting can stay changed, and the keys might stay lit while the phone sleeps. Nothing else watches for that yet. To fix it, open Shizuku and tap Start, then tap Stop & restore in NightKeys. If that doesn’t work, pick a normal time in the phone’s own keyboard backlight settings and let us know.

Tip: don’t use the phone’s own keyboard-light quick tile while NightKeys is on. Both change the same setting. Pause NightKeys first.
