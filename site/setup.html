01

Check your phone

This first beta supports the Unihertz Titan 2 Elite on Android 16, in the phone’s main owner profile. The working baseline was tested on V02.00.04. The non-Elite Titan 2 and other phones are not supported by this release.

  1. Open your phone’s Settings app, the one with the gear icon.
  2. Open About phone. If you cannot find it, use the search box at the top of Settings.
  3. Check Android version and Build number. The model may say “Titan 2” even on an Elite; the build display should identify the Elite.
  4. Connect to a trusted Wi-Fi network. Wireless Shizuku setup needs Wi-Fi. Keep this guide open on your phone or a second screen.

You should have: a Titan 2 Elite, Android 16, and Wi-Fi connected.

What are NightKeys and Shizuku?

NightKeys decides when the keyboard should light up. Shizuku is a separate, open-source helper that gives apps you approve access to Android’s debugging privileges. It is more powerful than an ordinary app permission. Only authorize apps you trust. You do not need to root the phone, unlock its bootloader, replace your keyboard app, or use a computer for this setup.

02

Install Shizuku

  1. Open the official Shizuku download page. Use its Google Play link, or its official GitHub release if Play is unavailable.
  2. Tap Install. Then tap Open.
  3. If asked, allow Shizuku notifications. You will use its pairing notification in a moment.
  4. It is normal to see “Shizuku is not running” at this point. Installing the app does not start its privileged service.

You should see: the Shizuku home screen. “Not running” is expected for now.

I downloaded a Shizuku APK instead of using Play

Use only the APK linked by the official Shizuku project, not a download mirror. Open the downloaded file. Android may ask you to allow installations from your browser; allow that source temporarily, go back, and tap Install. You can turn that source permission off again afterwards. Do not disable Play Protect. If Android reports that the app is harmful, stop and verify the file and source.

03

Enable Android’s debugging controls

This makes Android’s built-in debugging controls visible. Do not enable OEM unlocking or unlock the bootloader.

  1. In Settings → About phone, find Build number. On some layouts it is inside a software information screen.
  2. Tap Build number seven times. Enter your phone’s own PIN when Android asks. Never share that PIN with anyone.
  3. Go back to Settings. Search for Developer options and open it. It may be under System.
  4. Follow Shizuku’s setup prompt to enable USB debugging and Wireless debugging. If Android asks whether to allow debugging on this Wi-Fi network, confirm only on a network you trust.
  5. Tap the Wireless debugging row itself to open its detail screen, not just the small on/off switch.
Settings → About phone → Build number × 7
Settings → System → Developer options → Wireless debugging

You should see: Wireless debugging is on, with a “Pair device with pairing code” option.

04

Pair, then start Shizuku

  1. Return to Shizuku and tap Pairing in the wireless-debugging section. Follow its shortcut back to Developer options if offered.
  2. In Wireless debugging, tap Pair device with pairing code. A small window shows a six-digit code. Leave that window open.
  3. Swipe down from the top of the screen to open notifications. Expand the Shizuku pairing notification and tap Enter pairing code.
  4. Type those six digits and send them. The code changes or expires if you close the pairing window, so generate a fresh one if it fails.
  5. Return to Shizuku. Tap Start under wireless debugging. Wait for the startup text to finish.

You should now see: “Shizuku is running.” Pairing and starting are two separate steps.

No pairing notification, or it keeps searching?

Long-press the Shizuku app icon → App info → Notifications, and allow notifications. Check that you are on Wi-Fi and that Wireless debugging is on. Keep the pairing-code window open and generate a new code. If it still searches, follow Shizuku’s official troubleshooting guide. Do not change unrelated security settings.

05

Install NightKeys

Community beta 1.0.0-beta.1. This is the installable app, not a source-code ZIP. You do not need a GitHub account to download a release.

Download NightKeys APK

Release notes, checksum and known limitations

  1. On the phone, tap the download button above. If the browser asks whether to keep an APK file, check that the filename is NightKeys-1.0.0-beta.1.apk and that it came from this project’s GitHub release.
  2. Open the completed download from the browser, or open Files → Downloads and tap the APK.
  3. If Android says your browser cannot install unknown apps, tap Settings on that prompt. Turn on Allow from this source for that browser, then go back to the installer.
  4. Tap Install, then Open. You can switch “Allow from this source” off again after installation.

You should see: the NightKeys welcome screen with a “Connect Shizuku” button.

Already using a private 0.9.x test build?

Open the old app and use Stop & restore first. Confirm there are no pending hardware changes in its support report. Then uninstall that old test build before installing this beta. The community release uses a new permanent signing key, so Android cannot update the older test-signed app in place. Future community releases are intended to use the same key.

Android blocks the download or installation

Do not disable Play Protect or install a random replacement. Check the exact release source, APK filename, supported Android version and whether an older test-signed NightKeys is already installed. The app is not a ZIP: “Source code” is for developers. A harmful-app warning needs investigation; report it rather than bypassing it blindly.

06

Connect and choose your brightness

  1. In NightKeys, tap Connect Shizuku.
  2. Approve the Shizuku permission prompt for NightKeys. Choose Allow all the time so it can control lighting while you use other apps.
  3. Wait until NightKeys reports “Shizuku authorized ✓ · agui_common ready ✓.” The technical name means the phone’s keyboard-control service answered.
  4. Tap Open keyboard brightness settings. If you land on Display settings, find Keyboard backlight there or search Settings for it.
  5. Move the keyboard-brightness slider to the lowest level that you can comfortably see in the dark. NightKeys does not change that brightness. On the maintainer’s phone the minimum visible value is 7; you do not have to enter a number.
  6. Return to NightKeys. Leave the darkness threshold at its starting value of 10 lux for the first check.

You should see: Shizuku connected, a live light reading, and the keyboard-check button enabled.

What if a setting is missing?

You do not need an automatic-keyboard-brightness switch. Some firmware does not have one. If the vendor service check fails, stop here and use Copy support report. Do not try random developer settings or commands. Other Elite firmware is not automatically compatible.

07

Check the keyboard, then enable NightKeys

The 90-second check is temporary. It restores your settings when it ends. Running the check alone does not leave NightKeys enabled.

  1. Go somewhere dark. Tap Check my keyboard · 90 seconds, read the explanation, then begin. Allow NightKeys notifications when asked; its quiet notification has a safe stop button.
  2. With the screen on, wait at least 45 seconds without typing. The keyboard should stay lit at your chosen brightness.
  3. Press the power button to lock the screen. Watch for a few seconds: the keyboard should turn off and stay off.
  4. Wake the phone in darkness. The keyboard should light again. Then move into a bright room or uncover the light sensor; the keyboard should switch off. Do not use the stock keyboard-light Quick Settings tile during this check.
  5. Return to NightKeys and tap Save successful check. Tick only the behaviors you actually observed. Save. If any check failed, do not tick it; stop and report the issue.
  6. Wait for restoration to finish, then tap Enable NightKeys. This is the step that starts everyday automation.

You should see: active automatic lighting and a quiet NightKeys notification. It should keep working when you leave the app.

08

Everyday use, restart and safe removal

  1. In NightKeys, tap Open NightKeys battery & app settings. Find Battery or App battery usage. Choose Unrestricted if offered so the phone does not pause the monitor. Do the same for Shizuku if it keeps stopping. Menu names can differ by firmware.
  2. After a phone restart: connect to Wi-Fi, enable Wireless debugging again if it is off, open Shizuku and tap Start. Then open NightKeys. Pairing is usually remembered; starting the service is still necessary. If automation does not resume, use Enable NightKeys.
  3. To pause NightKeys, use Stop & restore in the app or notification. Avoid Force stop or task-killer apps while a keyboard change is active.
  4. Before uninstalling, clearing data, or returning to a test build: start Shizuku, tap Stop & restore, and verify that the support report says “No pending hardware changes.” Only then uninstall.

If NightKeys or Shizuku is killed, the stored timeout can remain changed. On the tested firmware this can include keyboard light while the screen is off. There is no independent fail-safe watchdog in this beta.

The keyboard is stuck on or off

Start Shizuku again, open NightKeys, and tap Stop & restore. Keep app data until restoration succeeds. If the app cannot recover, open the phone’s Keyboard backlight settings and select a normal finite duration, such as 30 seconds, as a manual recovery measure. That is not a promise to recover your previous preference. Keep the support report and report the problem.

Why shouldn’t I use the stock keyboard-light tile?

Both controls edit the same vendor timeout. The stock tile can replace NightKeys’ active setting with its saved duration. Pause NightKeys first; this beta deliberately does not take over the tile’s backup setting.

You’re done. Lower the threshold if the light comes on too often; raise it if you want it on in a brighter room.
