Titan Tools / Scale Toggle

Phone or tablet.
One long press.

Many apps keep their best layout for tablets: a list and the open chat side by side, more on screen at once. Scale Toggle flips your Titan 2 Elite between a phone layout and a tablet layout whenever you long-press the red side button.

Two sizes.
Nothing else touched.

Scale Toggle changes one setting: Android’s display density, the same one behind Display size. Each long press switches to the other size.

01 / PHONE MODE

Big and thumb-friendly.

A comfortable phone-sized layout: large text and buttons, one thing on screen at a time. Good for walking around and quick replies.

02 / TABLET MODE

Room for two panes.

Exactly 287 DPI, which makes the screen about 600 dp wide. That’s where many apps switch to their tablet layout, with lists and details side by side.

03 / NOTHING ELSE

Your settings stay yours.

Font size, screen resolution and rotation are never changed. No background service, no notification, no Internet permission. It switches, says so, and closes.

Tick boxes are just for you to keep your place. They’re saved only in this browser and don’t control the app.

Start here: download Scale Toggle

Scale Toggle is free. It’s tuned for the Unihertz Titan 2 Elite’s screen.

Download Scale Toggle

The file is called ScaleToggle-1.0.4.apk. “.apk” just means an Android app file.

  1. Tap Download Scale Toggle above, on your Titan 2 Elite.
  2. When the download finishes, tap Open. (Missed it? Open the Files app → Downloads.)
  3. Tap Install. If your phone says it can’t install apps from this browser, tap Settings, turn on Allow from this source, then go back and tap Install.
  4. Tap Done, not Open. You’ll open it in step 2.

You should now see: a Scale Toggle icon in your app drawer.

Already have an older Scale Toggle?

1.0.2 or 1.0.3: install straight over it. Don’t uninstall first. Your side-button shortcut and Shizuku permission carry over.

1.0.0 or 1.0.1: those used a different signing key, so your phone won’t update them. Switch to Phone mode with the old app, uninstall it, then install this one.

01

Start Shizuku, the helper app

Why Shizuku? Android only lets the system change display size. Shizuku gives Scale Toggle that one permission safely, without “rooting” (hacking) your phone. It’s the same helper NightKeys uses.

  1. Don’t have Shizuku yet? Follow the NightKeys guide’s step 1 to install it, then step 2, parts A–C to pair it. You only pair once.
  2. Open Shizuku and tap Start (under Start via Wireless debugging).
  3. Wait a few seconds until Shizuku says Running.

You should now see: Shizuku saying Running at the top.

Restarted your phone? Shizuku switches off on every restart. Turn on Wi-Fi, open Shizuku and tap Start again before using Scale Toggle.

Next: step 2 ↓
02

Allow Scale Toggle

Scale Toggle has no screen of its own. Opening it is the switch.

  1. Open your app drawer and tap Scale Toggle.
  2. A Shizuku box asks whether to allow Scale Toggle. Tap Allow all the time. (You’re only asked the first time.)
  3. Watch the screen: everything gets a little smaller, and a short message appears at the bottom.
  4. Tap Scale Toggle again to switch back.

You should now see: Tablet mode or Phone mode at the bottom of the screen, and the layout changes size. No numbers, no app window.

Next: step 3 ↓
03

Bind it to the side button

Scale Toggle is meant to live on a long press of the red side button, so switching never takes more than a second.

  1. Open Settings and search for shortcut. Open Shortcut keys.
  2. Choose the red side button (it may be called the programmable key).
  3. Tap Long press, choose Open app, then pick Scale Toggle.
  4. Leave Short press as it is, so the button still does whatever you use it for today.

You should now see: a long press on the red side button shows Tablet mode. Long-press again for Phone mode.

Menu names can differ slightly between phone software versions. Any app shortcut works too, because Scale Toggle is just an app that switches when it opens.

Stuck? Quick fixes

“Start Shizuku, then reopen Scale Toggle”

Shizuku isn’t running, usually because the phone restarted. Turn on Wi-Fi, open Shizuku and tap Start, then long-press the side button again. If Start fails, turn Wireless debugging off and on in Developer options.

“Allow Scale Toggle in Shizuku”

Scale Toggle was denied, or the permission box was missed. Open Shizuku, open its list of authorized applications, and turn on Scale Toggle. Then try again.

Nothing happens when I long-press the side button

First open Scale Toggle from the app drawer. If that switches, the shortcut isn’t set: repeat step 3 and make sure you set Long press, not Short press.

An app looks odd right after switching

Most apps redraw themselves instantly. If one looks cramped or stretched, close it from Recents and open it again. Tablet mode is set to exactly 287 DPI because going any smaller stopped WhatsApp from opening on the maintainer’s phone.

Going back to normal, or uninstalling

Long-press the side button until you see Phone mode before you uninstall. The display size you’re on stays after the app is removed. If you uninstalled in Tablet mode, open Settings → Display → Display size and text and drag Display size back to the size you like.

Scale Toggle is a small community tool. Tablet mode always applies 287 DPI. It was tuned on the maintainer’s Titan 2 Elite at 1076 × 1200; on a different resolution the layout width can differ a little. Release notes and source
