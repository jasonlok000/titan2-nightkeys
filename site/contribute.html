A little help from each other.

A firmware report, a clearer sentence, or a small pull request can make a real difference. There’s a useful first contribution for everyone.

01

Test it on your phone

Use the setup guide and tell us your exact Elite firmware, whether it passes all four lighting checks, and what happens after a reboot. A settings readback alone is not a physical test.

02

Make the guide clearer

You don’t need a development environment. Open the guide’s source on GitHub, click the pencil, change a confusing step, and propose the edit. GitHub will offer to create a fork if needed.

03

Fix a bug or build a feature

Read the architecture and safety notes first. Changes to privileged commands, screen-off behavior, or recovery need tests and a physical-device check before we call them supported.

A home for the next useful thing.

NightKeys is the first tool, not a promise of a giant suite. Bring an idea that solves a specific Titan problem. Open a proposal before writing a large feature so we can agree on scope, permissions and safety.

The shared catalogue lives in site/data/tools.json. New tools can have their own repository or Android module and still appear here, with a guide and source link. Only working, reviewed tools should be marked available.

Propose a tool or improvement

Your first contribution, step by step.

  1. Create a free GitHub account if you do not have one. You need an account to open an issue or propose changes, but not to download NightKeys.
  2. For a bug, open the bug-report link below. Describe what you expected and what you saw, with clear steps to repeat it.
  3. In NightKeys, use Copy support report. Review it, remove anything you do not want public, and paste it into the report. Do not include passwords, pairing codes, signing keys or personal screenshots.
  4. For a code or documentation change, fork the repository, make a focused change on a new branch, then open a pull request back to this project. The developer guide has the exact commands.
  5. Be kind, explain your testing, and wait for review. Passing automated tests does not automatically prove a different firmware works.
