Titan Tools / Privacy

Just the light.
Not your life.

NightKeys does not need your words, contacts, camera, or location to know whether the room is dark.

Inside the Android app

NightKeys reads ambient-light measurements, screen state, basic phone/firmware information and a small allow-list of vendor keyboard settings. It changes only keyboard_brightness_timeout and sends the vendor close-light broadcast. Keyboard brightness and the stock tile’s backup value are left alone.

The app has no Internet permission, ads, analytics, login, location access, camera access, microphone access, contacts access, or keyboard-input recording. Opening the guide or Shizuku download page launches your own browser; those sites then receive a normal web request.

Why Shizuku and a notification?

Shizuku lets NightKeys run the small set of privileged commands needed to reach the vendor keyboard service. That access is powerful, so review the source and authorize only apps you trust. A foreground-service notification shows that automatic lighting is running and provides Stop & restore. A short, bounded wake lock helps complete shutdown work; NightKeys does not deliberately keep the display awake.

What is saved locally?

Your threshold, setup confirmation, resume preference, last error and original timeout are stored in private app preferences. Backup is disabled. The original timeout is a recovery record and is cleared after successful restoration. Do not clear app data while a change is pending.

Support reports are your choice

A report is generated and copied only when you request it. It can contain firmware, ambient light, current keyboard values and an error message. Nothing is submitted automatically. Review the text before posting it to a public issue. It does not include a device serial number or typed text.

This website

This static site has no analytics, advertising, third-party fonts or tracking scripts. The optional setup checklist is stored only in your browser’s local storage; Reset my checklist removes it. The interactive phone is an illustration, not access to your real phone or sensors.

GitHub Pages hosts the site and GitHub hosts downloads and issues. Those services process ordinary connection information, such as IP addresses, under GitHub’s privacy statement. Links to Shizuku or other projects follow their own policies.

Removing NightKeys

Start Shizuku, use Stop & restore, confirm there are no pending hardware changes, and then uninstall. Uninstalling alone does not reliably undo vendor settings. Read the safe-removal guide before deleting data.
